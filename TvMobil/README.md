# TV Mobil
App Android (Kotlin + Jetpack Compose + Media3). Agrega playlists M3U (iptv-org u otras), lista/busca canales y los reproduce (HLS/DASH/progresivo).
Abrir la carpeta en Android Studio ( Koala o superior) > Sync > Run. Build > Build APK para generar el .apk.
Ejemplos: https://iptv-org.github.io/iptv/index.m3u , https://iptv-org.github.io/iptv/countries/<codigo>.m3u
